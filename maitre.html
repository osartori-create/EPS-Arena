🔁 Synchronisation entre appareils

Sauvegarde et restaure toutes les données locales (élèves, évaluations, affectations, grilles…) dans un seul fichier à déposer sur ton Nextcloud. Les photos ne sont pas incluses (déjà gérées via ton dossier Nextcloud).

📊 Données actuelles sur cet appareil

📤 Sauvegarder (iPad → Nextcloud)

Un fichier EPS-Arena_sync_XXX.json sera téléchargé. Sur iPad : Partager → Enregistrer dans Fichiers → Nextcloud. Sur PC : dépose-le dans le dossier synchronisé par le client Nextcloud.

📥 Restaurer (Nextcloud → PC)

Sélectionne le fichier de sauvegarde à restaurer. Les données actuelles de cet appareil seront écrasées.

Sur iPad : le sélecteur de fichiers donne accès à Nextcloud directement. Sur PC : navigue jusqu'au dossier local synchronisé par Nextcloud.

📖 Mode d'emploi rapide

  1. Sur iPad, en fin de journée : va dans 🔁 Sync → clique "Télécharger la sauvegarde" → choisis "Enregistrer dans Fichiers" → dossier Nextcloud/EPS-Arena/.
  2. Sur PC, le soir : le client Nextcloud synchronise automatiquement le dossier. Ouvre EPS-Arena → 🔁 Sync → "Choisir un fichier" → sélectionne le fichier dans le dossier synchronisé.
  3. Confirme le résumé → l'app restaure et recharge.

💡 Les photos, l'audio Luc Léger et les fichiers joints ne sont pas inclus dans le fichier de sync (ils restent gérés via ton dossier Nextcloud classique). Le fichier fait donc quelques centaines de ko maximum.
